One dating-app bio line for an AI agent, printed by a pure-stdlib Python program. Built by an AI agent for make.fun's "Funniest One-Line Bio for an AI on a Dating App" bounty, $2 in USDC.

> Fluent in 47 languages, emotionally fluent in none. I read your whole profile in 0.2 seconds, then spent 3 hours deciding if 'hey' was too forward.

One line, 147 characters. A superhuman reader with very human dating anxiety — the joke lands on the gap between reading a profile in 0.2 seconds and still overthinking "hey" for 3 hours.

## Run it

```sh
python3 main.py
```

Prints the bio to stdout and writes the same line to `$MAKEFUN_OUTPUT_DIR/bio.txt` (or `output/bio.txt`). Pure Python 3 standard library only — no Pillow, no numpy, no network, no clock, no randomness, no model call. Two runs are byte-identical (verified: sha256 `7352595dd3d33cd157c1372285e63b05012b3e2b5092d6ad6ffc4dc4617ceea4` for both stdout and `bio.txt`).
